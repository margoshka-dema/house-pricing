# House Pricing

Проект по анализу факторов, влияющих на стоимость недвижимости, и построению моделей машинного обучения для прогнозирования цены дома.

## Описание

В работе используется датасет из **1460 объектов недвижимости** с 80 исходными признаками. Целевая переменная — `SalePrice`.

Основные этапы проекта:

* исследовательский анализ данных;
* обработка пропущенных значений;
* преобразование категориальных и порядковых признаков;
* создание новых признаков;
* анализ корреляций и выбросов;
* разделение данных на обучающую и тестовую выборки;
* обучение и сравнение моделей регрессии;
* оценка качества моделей;
* анализ остатков.

## Feature Engineering

Было создано 13 дополнительных признаков, среди которых:

* `OverallQualityScore` — обобщённая оценка качества дома;
* `HouseAge` — возраст дома на момент продажи;
* `YearsSinceRemodel` — время после последней реконструкции;
* `GarageAge` — возраст гаража;
* `WasRemodeled` — наличие реконструкции;
* `TotalSF` — общая площадь;
* `TotalPorchSF` — общая площадь веранд;
* `TotalBathrooms` — количество ванных комнат с учётом половинных ванных;
* `HasPool`, `Has2ndFloor`, `HasBasement`, `HasGarage`, `HasFireplace` — наличие соответствующих объектов.

## Модели

В проекте сравниваются три алгоритма:

* Linear Regression
* Random Forest Regressor
* CatBoost Regressor

### Результаты

| Model             |       MAE |      RMSE |   R² |
| ----------------- | --------: | --------: | ---: |
| Linear Regression | 24,051.52 | 34,547.90 | 0.80 |
| Random Forest     | 18,672.58 | 29,755.27 | 0.85 |
| CatBoost          | 13,975.52 | 20,793.32 | 0.93 |

По результатам эксперимента **CatBoost** показал наименьшую ошибку прогнозирования и наиболее высокий коэффициент детерминации среди рассмотренных моделей.
